# MPBaptista

Personal landing page for Miguel Baptista. A single static page with an about section, contact links and a projects section.

## Structure

```
index.html    Page markup and content
styles.css    Styles, including light and dark themes
theme.js      Dark / light mode toggle (follows the OS setting until changed)
images/       Project previews
```

## Running locally

No build step or dependencies are needed. Open `index.html` in a browser.


## Editing content

- Text, contact links and project cards live in `index.html`.
- Colours are defined as tokens at the top of `styles.css`.
- The footer's "Last updated" date is typed in by hand in `index.html`.
